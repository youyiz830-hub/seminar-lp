## 公開前に置換が必要なプレースホルダー

`index.html` 内の以下の文字列を実際の値に置き換えてください。

| プレースホルダー | 内容 |
|---|---|
| `{{FUKUOKA_PEATIX_URL}}` | 福岡会場のPeatix申込みURL |
| `{{ONLINE_PEATIX_URL}}` | オンライン開催のPeatix申込みURL |
| `{{APPLICATION_DEADLINE}}` | 申込み期限（例: 2026年9月12日（土）など） |
| `{{CANONICAL_URL}}` | 公開するドメイン（例: https://example.com） |

**検索して置換する方法（VS Codeなど）:**
- `Ctrl+H`（macOS: `Cmd+H`）で検索・置換ダイアログを開く
- 上記プレースホルダーをそのまま検索し、実際の値を入力して「すべて置換」

## Vercelへの公開手順（最短3ステップ）

### 前提
- [Vercelアカウント](https://vercel.com)を持っていること

### 方法A：ドラッグ＆ドロップ（最も簡単）

1. [vercel.com/new](https://vercel.com/new) を開く
2. `セミナーLP` フォルダをブラウザ画面にドラッグ＆ドロップ
3. 「Deploy」ボタンをクリック → 数分で公開完了

### 方法B：GitHub経由（推奨）

1. GitHubに新しいリポジトリを作成
2. `セミナーLP` フォルダの中身をリポジトリへプッシュ
3. Vercelダッシュボードでリポジトリを選択して「Import」→「Deploy」
4. 以後 `main` ブランチへプッシュするたびに自動で再デプロイされる

### カスタムドメイン設定

Vercelダッシュボード → プロジェクト → Settings → Domains → ドメインを追加
